# VZ1 压缩算法设计

## 1. 概述

VZ1 是 VelaPack 的默认编解码器，结合两种经典技术：

1. **LZ77 变种**：消除重复字符串
2. **规范霍夫曼编码**：消除统计冗余

与 DEFLATE 的主要区别：
- 64KiB 窗口（与 DEFLATE 相同）
- 最小匹配长度 4（DEFLATE 为 3），减少短匹配噪声
- 动态 Huffman 表按 4bit/符号直接存储，不做二次压缩（简化实现）
- 位流采用 MSB-first 顺序

## 2. LZ77 解析器

### 2.1 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 窗口大小 | 65536 | 滑动窗口字节数 |
| 最小匹配 | 4 | 短于此长度输出字面量 |
| 最大匹配 | 258 | 单次匹配长度上限 |
| 哈希位数 | 16 | 哈希表大小 65536 |
| 哈希函数 | `(x * 2654435761) >> 16` | Knuth 乘法散列，取 4 字节 |

### 2.2 惰性匹配（Lazy Matching）

级别 >= 2 时启用：

```
for each position:
    len1 = find_longest_match(pos)
    if len1 >= MIN_MATCH:
        len2 = find_longest_match(pos + 1)
        if len2 > len1:
            emit_literal(pos)
            pos++
        else:
            emit_match(len1, dist1)
            pos += len1
```

级别策略：

| 级别 | 模式 | 链搜索深度 |
|------|------|-----------|
| 1 | 贪婪 | 32 |
| 2-6 | 惰性 | 128 |
| 7-9 | 惰性 | 512 |

### 2.3 匹配查找优化

- 哈希链 + 前向数组（`prev[]`）实现 O(1) 插入
- 链搜索限制 `max_chain`，防止退化
- 快速校验：先比较 `pos + best_len` 处的字节，跳过明显不优候选

## 3. 符号编码

### 3.1 字面量/长度字母表（LL，286 符号）

| 符号 | 含义 |
|------|------|
| 0..255 | 原始字节 |
| 256 | 块结束（EOB） |
| 257..285 | 匹配长度码 |

### 3.2 长度码表

| 码 | 基础长度 | 附加位 |
|----|---------|--------|
| 257..264 | 4..11 | 0 |
| 265..268 | 12,14,16,18 | 1 |
| 269..272 | 20,24,28,32 | 2 |
| 273..276 | 36,44,52,60 | 3 |
| 277..280 | 68,84,100,116 | 4 |
| 281..284 | 132,164,196,228 | 5 |
| 285 | 258 | 0（特殊） |

### 3.3 距离字母表（D，32 符号）

距离编码为 `d' = dist - 1`，按对数区间划分：

| 码 | d' 范围 | 附加位 |
|----|---------|--------|
| 0..3 | 0..3 | 0 |
| 4,5 | 4..5, 6..7 | 1 |
| 6,7 | 8..11, 12..15 | 2 |
| ... | 按 2^n 递增 | ... |
| 30,31 | 32768..49151, 49152..65535 | 14 |

## 4. 霍夫曼编码

### 4.1 规范码（Canonical Code）

只存储每个符号的码长（4 bit），解码端按规则重建：
1. 按码长升序、同码长按符号升序排列
2. 从 0 开始连续分配码字
3. 每增加一位码长，码字左移一位

### 4.2 码长限制

最大 15 位。若 Huffman 树深度超限，采用 zlib 风格修正：
1. 超限叶子码长强制为 15
2. 从最深层开始，将一个叶子分裂为两个子叶
3. 重复直到 Kraft 和满足 `sum(2^-len) == 1`

### 4.3 位流布局

```
[143 字节] LL 码长表（286 符号，4bit/符号）
[16  字节] D  码长表（32 符号，4bit/符号）
[变长]     符号流 + EOB，最后补零对齐字节
```

## 5. 复杂度

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 压缩 | O(n × chain) | O(W + H) |
| 解压 | O(n) | O(block_size) |

- `chain`：级别决定的最大链搜索深度（32~512）
- `W`：窗口大小（64KB）
- `H`：哈希表大小（64KB）
